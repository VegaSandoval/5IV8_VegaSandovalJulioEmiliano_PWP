09Node — Servidor básico con Node.js

Vega Sandoval Julio Emiliano

Esta práctica demuestra cómo levantar un servidor sencillo en Node.js, gestionar dependencias con NPM y organizar un proyecto mínimo. El resultado es la carpeta 09Node/ con código de servidor, utilidades, un .gitignore adecuado y un package.json con dependencias.

Estructura obtenida

        09Node/
        ├─ node_modules/               (generado por npm install)
        ├─ .gitignore                  (ignora dependencias, logs, tmp, etc.)
        ├─ function.js                 (objeto con funciones: suma, resta)
        ├─ index.js                    (servidor HTTP básico)
        ├─ node.html                   (HTML de apoyo; no lo sirve el server actual)
        ├─ package-lock.json           (árbol exacto de dependencias)
        └─ package.json                (nombre, scripts, dependencias)

Cómo se llegó a este resultado (paso a paso)

  1. Crear carpeta y posicionarse: 
    mkdir 09Node
cd 09Node
  2. Inicializar NPM (crea package.json): 
    npm init -y
  3. Crear y completar .gitignore para evitar subir node_modules/, variables, logs, etc. 
    node_modules/
.env
.env.*
build/
dist/
npm-debug.log*
yarn-debug.log*
yarn-error.log*
*.log
.DS_Store
Thumbs.db
.vscode/
  4. Instalar dependencias (opcional para esta demo, pero registradas en el proyecto): 
    npm install express bootstrap
    Aunque se instaló Express, el servidor de la práctica usa el módulo nativo http.
  5. Crear el servidor en index.js: 
    // index.js
var http = require('http');

var servidor = http.createServer(function (req, res) {
  res.writeHead(200, {'Content-Type': 'text/html; charset=utf-8'});
  res.write('<h1>Hola Mundo desde Node.js</h1>');
  res.write('<h1>A mimir</h1>');
  console.log('Hola, sí entró al servidor');
  res.end();
});

servidor.listen(3000);
console.log('Servidor ejecutándose en http://localhost:3000');
  6. Código auxiliar en function.js: 
    // function.js
var prueba = {
  suma: function(a, b) {
    var c = a + b;
    console.log(c);
  },
  resta: function(a, b) {
    var c = a - b;
    console.log(c);
  }
}
    Estas funciones imprimen en consola; si se quieren usar en otros archivos, deben exportarse con module.exports.
  7. Ejecutar el servidor: 
    node index.js

    Verás en consola: Servidor ejecutándose en http://localhost:3000 y podrás abrir esa URL en el navegador.

Qué hace y cómo funciona

  • El módulo nativo http crea un servidor que responde con HTML plano a cualquier ruta.
  • El encabezado Content-Type: text/html; charset=utf-8 permite enviar texto con acentos.
  • La respuesta se arma con varias llamadas a res.write() y se finaliza con res.end().
  • El servidor escucha en el puerto 3000; si el puerto está ocupado, cámbialo (por ejemplo, 3001).
  • function.js es una utilidad separada; actualmente no se importa en index.js.

Errores comunes y mejoras sugeridas

  • Puerto en uso: cambia el listen(3000) o libera el puerto.
  • Faltan dependencias: si borraste node_modules/, corre npm install.
  • Bootstrap mal escrito: cambia "boostrap" por "bootstrap" en package.json y reinstala.
  • Mejorar arranque: agrega en package.json: 
    "scripts": {
  "start": "node index.js",
  "dev": "npx nodemon index.js"
}
    Ejecuta con npm run dev para recarga en caliente.
  • Servir HTML real: Puedes migrar a Express o leer un archivo con fs.readFile y enviarlo en la respuesta.

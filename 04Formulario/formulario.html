04Formulario

Vega Sandoval Julio Emiliano

Todos los formularios en la web manejan métodos para el envío de peticiones que realiza el usuario. Considerando la arquitectura Cliente-Servidor, el manejo de las peticiones se hace por medio del protocolo HTTP (o HTTPS). Cada petición debe ser atendida con un tiempo de respuesta conforme al modelo TCP/IP.

  • GET: Este método envía la información del formulario por la salida estándar (URL). Puede exponer datos y generar vulnerabilidades si no se valida correctamente.
  • POST: Envía información mediante un ocultamiento interno, no visible en la URL. Se usa para registrar o modificar datos de forma más segura.

En resumen, los métodos son:

  • GET: operaciones de lectura o consulta
  • POST: envío de información a un servidor
  • DELETE: eliminación de un recurso específico
  • PUT: actualización de un recurso
  • HEAD: devuelve encabezados HTTP asociados a un recurso
